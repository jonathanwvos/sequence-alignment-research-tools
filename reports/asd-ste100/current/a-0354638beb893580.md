## Executive summary

- The authors present WFA-GPU, a GPU-accelerated pairwise sequence aligner based on the wavefront alignment algorithm. (PDF p. 1).
- WFA-GPU adapts wavefront operations to GPU hardware using 16-base block comparisons and memory-coalesced diagonals. (PDF p. 6).

## Objectives

- Accelerate gap-affine pairwise alignment for high-throughput sequencing reads using commodity GPU architectures. (PDF p. 2).

## Arguments

- GPU architectures require high arithmetic density and low memory access overhead to achieve peak compute throughput. (PDF p. 3).

## Analysis

- Runtime and recall are measured on simulated and empirical PacBio HiFi and Oxford Nanopore read datasets. (PDF p. 8).

## Methods

- Wavefront diagonal expansions and match extensions are mapped to parallel GPU threads and warps. (PDF p. 3).
- Bit-parallel 32-bit operations compare 16-nucleotide blocks simultaneously to minimize thread divergence. (PDF p. 6).

## Applications

- Pairwise read alignment, de novo genome assembly verification, and read-to-reference mapping pipelines. (PDF p. 2).

## Optimization

- Block-based 16-base comparisons and shared memory caching reduce execution divergence and memory bandwidth demand. (PDF p. 6).

## Evaluation and testing

- WFA-GPU is benchmarked against CPU WFA and heuristic GPU aligners on simulated and real long-read datasets. (PDF p. 8).

## Results

- WFA-GPU achieves 2.7x to 4.8x overall speedup on PacBio and Nanopore reads compared to optimized CPU implementations. (PDF p. 8).

## Limitations and uncertainty

- Irregular wavefront shapes on highly divergent sequence pairs cause thread divergence and reduce GPU utilization. (PDF p. 6).
