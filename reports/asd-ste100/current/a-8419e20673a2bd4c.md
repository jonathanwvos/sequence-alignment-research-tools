## Executive summary

- The author gives an O(|G|²|B|²)-time algorithm for a longest topological common subsequence of a symbol-wise totally ordered DAG G and a sequence B. (PDF p. 2).
- The algorithm represents subsequences as independent sets of matching vertex-position pairs. (PDF p. 3).

## Objectives

- Find a longest common subsequence of B and any sequence specified by a topological sort of G. (PDF p. 1).

## Arguments

- Lemma 1 proves that a set of matching pairs represents a topological common subsequence exactly when it is independent. (PDF p. 3).
- An independent set contains at most one pair from each exclusive list. A partition into L such lists therefore gives an upper bound of L on subsequence length. (PDF p. 3).

## Analysis

- The paper uses the term maximal for an independent set of maximum size. (PDF p. 3).
- The runtime analysis assigns O(|G|²) time to reachability preprocessing and O(|G|²|B|) time to each sequence-position iteration. (PDF p. 7).

## Methods

- Create a matching pair (v, j) when vertex v has label B[j]. (PDF p. 2).
- For distinct pairs (u, j) and (v, k), define precedence when u reaches v or equals v, and j is at least k. Independent sets contain no such precedence relation. (PDF p. 3).
- Process prefixes of B in increasing order. Maintain a partition of matching pairs into exclusive lists and an independent set that selects one pair from each list. (PDF p. 3).
- Use breadth-first searches for reachability information and ordered lists of current matches. Valid suffix changes take constant time. (PDF p. 7).

## Applications

- The method can add a sequence to an irredundant multiple alignment while allowing column orders that preserve each original sequence. (PDF p. 2).
- A generalized matching rule permits columns with several similar symbols. Matching must take constant time, and all vertices matching an element must lie on one path. (PDF p. 7).

## Optimization

- The ordered match list permits a forward scan when assigning new pairs to lists. This step takes O(L² + |G|) time, where L is the previous number of exclusive lists. (PDF p. 7).
- Each matching pair is subject to at most one valid suffix change during the analyzed iteration. This bounds the suffix-change work by O(|G||B_j|). (PDF p. 7).

## Results

- The author derives a total running time of O(|G|²|B|²). Here |G| counts vertices and |B| is sequence length. (PDF p. 7).

## Limitations and uncertainty

- The method requires all vertices with a given symbol to occur on one path of G. (PDF p. 2).
- Polynomial-time solvability remains open when both inputs are arbitrary symbol-wise totally ordered DAGs. (PDF p. 7).
- Graph prefixes used for path-based alignment do not directly support the topological-sort problem. (PDF p. 8).
