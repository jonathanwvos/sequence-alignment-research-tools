## Executive summary

- ACS averages the longest match between each suffix of X and any suffix of Y. (PDF p. 2).
- The authors present an algorithm for run-length encoded inputs with O(N log N) time and O(N) space, where N is the total number of encoded runs. (PDF p. 1).

## Objectives

- The authors seek time and space costs based on compressed input size N instead of uncompressed size n. (PDF p. 2).

## Arguments

- The authors motivate computation on compressed sequences with little or no decompression. The standard generalized suffix tree method uses O(n) time and space. (PDF p. 1).

## Analysis

- The algorithm uses a trie of suffixes that start at run boundaries. The trie has N leaves, at most N − 1 internal nodes, and O(N) words of storage. (PDF p. 3).
- Each internal trie node stores its node depth and the common-prefix length of its descendant suffixes. Leaves identify whether their suffix comes from X or Y. (PDF p. 3).
- The final algorithm computes one contribution per run in O(log N) time. Together with construction, this gives O(N log N) total time. (PDF p. 5).

## Methods

- Each encoded item stores a character and its run length. Consecutive runs have different characters. (PDF p. 2).
- The authors construct a generalized suffix tree for the encoded inputs and convert it to a trie of corresponding uncompressed suffixes at run boundaries. (PDF p. 3).
- The algorithm defines A[i] as the sum of longest-match lengths for positions in run i. It sums these contributions and divides by the length of X to obtain ACS(X,Y). (PDF p. 5).
- For each nonfinal run, binary search with level-ancestor queries finds ancestors that meet type-Y and frequency conditions. Weighted depths and arithmetic sums give the run contribution; the final run uses a separate arithmetic formula. (PDF p. 5).

## Applications

- The authors identify phylogeny reconstruction as an application of the alignment-free ACS distance measure. (PDF p. 1).

## Optimization

- The final algorithm aggregates matches by run instead of computing each position separately. The earlier algorithm has a stated O(n log N) time bound. (PDF p. 3).
- A top-down traversal computes cumulative node weights across the character-specific tries in O(N) time. The run formulas reuse these weights. (PDF p. 5).

## Evaluation and testing

- The analysis gives a construction lemma with O(N log N) time and O(N) space for the trie. (PDF p. 3).
- The authors derive the final complexity from construction and per-run queries. They state that correctness follows from Observation 2 and the node-weight definition. (PDF p. 5).

## Results

- Theorem 1.1 states that the symmetric distance based on ACS can be computed from run-length encoded inputs in O(N log N) time and O(N) space. (PDF p. 2).
