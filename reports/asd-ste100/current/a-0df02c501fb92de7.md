## Executive summary

- The authors formalize the string-to-string correction problem and present the classic O(mn) dynamic programming algorithm. (PDF p. 1).
- Edit distance is defined as the minimum-cost sequence of character insertions, deletions, and substitutions. (PDF p. 1).

## Objectives

- Compute the minimum-cost edit script transforming string A of length m into string B of length n. (PDF p. 1).

## Arguments

- Optimal edit scripts possess optimal substructure, allowing inductive dynamic programming computation. (PDF p. 3).

## Analysis

- The time and space complexity are established as proportional to the product of sequence lengths O(mn). (PDF p. 2).

## Methods

- A dynamic programming recurrence computes prefix edit distances D(i, j) from adjacent matrix cells. (PDF p. 2).
- Traceback through the dynamic programming matrix reconstructs the optimal sequence of edit operations. (PDF p. 3).

## Applications

- Spelling correction, longest common subsequence computation, and biological sequence alignment. (PDF p. 2).

## Optimization

## Results

- Establishes the foundational O(mn) dynamic programming algorithm that underlies sequence alignment theory. (PDF p. 2).

## Limitations and uncertainty

- The quadratic time and space complexity O(mn) becomes prohibitive for long sequences without heuristics. (PDF p. 2).
