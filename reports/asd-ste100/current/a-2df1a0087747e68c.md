## Executive summary

- The authors present an LCS algorithm with O((r + n) log n) time, where r counts matching position pairs in two sequences of length n. (PDF p. 1).
- The algorithm recovers an actual LCS and uses O(r + n) space. (PDF p. 4).

## Objectives

- The authors aim to reduce computation when each sequence position matches few positions in the other sequence. (PDF p. 2).

## Arguments

- The authors argue that the number of matching position pairs is a useful performance parameter. When r is O(n), their time bound becomes O(n log n). (PDF p. 2).

## Analysis

- A threshold T[i,k] gives the shortest prefix of B that supports a common subsequence of length k with A[1:i]. Defined thresholds increase strictly with k. (PDF p. 2).
- The main loop processes exactly r matching pairs. Each pair requires one binary search and constant additional work. (PDF p. 4).
- Matching positions in B must be processed in decreasing order. Increasing order can incorrectly use one position in A to extend several subsequence lengths. (PDF p. 3).

## Methods

- Algorithm 2 builds decreasing lists of matching positions in B. Equal elements in A share the same physical list. (PDF p. 3).
- For each matching position j, binary search finds k such that THRESH[k−1] < j ≤ THRESH[k]. The algorithm lowers THRESH[k] when j is smaller. (PDF p. 3).
- Each threshold decrease creates a node with the matching position pair and a predecessor pointer. Following these pointers recovers an LCS in reverse order. (PDF p. 4).

## Applications

- The authors identify applications in ascending subsequences of permutations, ordered subsets of two-dimensional vectors, and file comparison with lines as atomic elements. (PDF p. 2).

## Optimization

- Sorting both sequences with their original positions, then merging them, builds the shared match lists in O(n log n) time and O(n) space. (PDF p. 4).
- A theoretical implementation with van Emde Boas structures reduces time to O(r log log n + n log n) for an infinite alphabet. (PDF p. 4).
- For a fixed finite alphabet, distribution sorting gives O((n + r) log log n) time with the same structures. For a permutation, r = n gives O(n log log n) time. (PDF p. 4).

## Evaluation and testing

- Correctness is supported by threshold lemmas and loop invariants. The invariants connect each updated threshold array to the next prefix of A. (PDF p. 3).
- The resource proof analyzes preprocessing, threshold updates, node allocation, and LCS recovery separately. (PDF p. 4).

## Results

- Theorem 1 establishes O((r + n) log n) time and O(r + n) space for Algorithm 2. (PDF p. 4).

## Limitations and uncertainty

- The worst-case time is O(n² log n), since r can reach n². (PDF p. 1).
- Some repetitive inputs require O(r) space even when inaccessible reconstruction nodes are reclaimed. (PDF p. 4).
- The authors describe the van Emde Boas implementation as complex and present its improvement as a theoretical result. (PDF p. 4).
