## Executive summary

- Hirschberg presents an algorithm that constructs a longest common subsequence in quadratic time and linear space. (PDF p. 1).
- The method combines row-based dynamic programming with recursive division into smaller string-pair problems. (PDF p. 2).

## Objectives

- The aim is to reduce memory use while retaining quadratic time for longest common subsequence construction. (PDF p. 1).

## Arguments

- The author argues that storing the full quadratic matrix can exceed main-memory capacity even when the computation time is acceptable. (PDF p. 1).
- Only the preceding matrix row is needed to compute the next row. This permits linear-space computation of length vectors. (PDF p. 2).

## Analysis

- Algorithm A computes mn matrix entries and requires O(mn) time and space. (PDF p. 2).
- Algorithm B computes the final length vector in O(mn) time and O(m + n) space, including input and output storage. (PDF p. 2).
- The split theorem states that maximizing the sum of prefix and suffix subsequence lengths over split positions in B gives the full optimum. (PDF p. 2).
- The recursive time analysis establishes an O(mn) bound for Algorithm C. (PDF p. 3).

## Methods

- Algorithm A adds one to the diagonal value when symbols match. Otherwise, it takes the larger value from the preceding row or column. (PDF p. 1).
- Algorithm B retains two rows and returns the longest common subsequence lengths for the full first string against each prefix of the second. (PDF p. 2).
- Algorithm C halves A and runs Algorithm B on forward and reversed substrings. It selects the earliest split in B that maximizes the combined lengths. (PDF p. 2).
- Algorithm C recursively solves the two resulting problems and concatenates their subsequences. Empty-string and single-symbol cases are solved directly. (PDF p. 2).

## Applications

- The algorithm constructs a common subsequence of maximum length for two strings. (PDF p. 2).
- The author describes an edit-distance adaptation that minimizes combined prefix and suffix costs and applies the same recursive split. (PDF p. 3).

## Optimization

- Two-row storage removes the need to retain the complete matrix during length computation. (PDF p. 2).
- Recursive splitting uses length vectors to recover a longest common subsequence in linear space. (PDF p. 2).

## Evaluation and testing

- Algorithm B is verified by induction through equivalence with the full-matrix recurrence. (PDF p. 2).
- Algorithm C is verified through the split theorem, which ensures that concatenating optimal subproblem solutions gives a full optimal solution. (PDF p. 3).
- The numerical time and memory examples use assumed per-operation and per-location coefficients. They are illustrative estimates. (PDF p. 1).

## Results

- The paper gives a longest common subsequence algorithm with quadratic time and linear space. (PDF p. 1).
- The correctness proof shows that Algorithm C returns a common subsequence of length L(m,n), the maximum possible length. (PDF p. 3).
