# Research sources

Checked 2026-09-23. This is a targeted extension of the local review, not an exhaustive systematic search. No local PDFs or project data were uploaded. External entries are candidates for review, not approved development work.

`inspected` records reading depth. Abstract-only entries support broad capability tags, not detailed recurrence, complexity, absence or correctness claims. A local hash identifies the inspected copy; it does not certify it as the definitive publication. Repository documentation is separate from historical article evidence.

Search clusters: compressed/RLE edit distance; differentiable DP/DTW and OT; protein embeddings and MSA; exact graph alignment including cycles; GPU alignment output contracts; alignment-free sketches. The search deliberately broadens the earlier exclusions in [SEARCH_METHOD.md](../SEARCH_METHOD.md).
