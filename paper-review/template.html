Research tools

Review the rendered paper

Hover over a highlighted superscript to compare the PDF citation with the current reference list and read its ASD report excerpt. Click the superscript to record a judgment. The preview helps you check a claim; it does not verify it automatically.

Select words or click a line of manuscript text, then choose as many sources as needed. Each choice attaches immediately and can be removed with ×. Additions stay in this browser until you save the JSON. The PDF is a snapshot of the current rendered manuscript.

Your saved review belongs to an earlier PDF, reference list, or corpus index. Save its JSON before starting a new review.

Attach a reference

Select text or click a manuscript line.

Choose a source to attach it immediately to the selected text. Choose more sources to build the citation list; use × to remove one.

Pending citation removals

After compiling a new PDF, refresh this static viewer from the repository root with python3 'docs/Literature Review/Research Tools/paper-review/build.py', then reload this page.

To apply queued removals from a newly exported review, run python3 'docs/Literature Review/Research Tools/paper-review/apply_review.py' 'docs/Literature Review/vala-manuscript-citation-review.json' --apply. An already-applied JSON cannot be reused.

Session additions

The JSON stores page and source locations, source hashes, citation decisions, removals, and proposed additions. Additions still require separate manuscript editing.
